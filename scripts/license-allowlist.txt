# Default licence allowlist: what an Apache-2.0 project may depend on.
#
# Read by osv.jq when `licenses_allowlist` is `default`. SPDX identifiers, one
# per line, matched case-insensitively against each package's licence
# expression (OR / AND / WITH / parentheses - see scripts/spdx.jq). An allowed
# base licence allows its `WITH` exceptions; a banned base needs the exact
# `X WITH exception` line.
#
# The split is the Apache Software Foundation's third-party licence policy,
# https://www.apache.org/legal/resolved.html: Category A (permissive) and
# Category B (weak copyleft - fine to depend on and ship unmodified; the
# copyleft reaches only that package's own files) are in. Category X - GPL,
# LGPL, AGPL, SSPL, BUSL, the Commons Clause, CC non-commercial / no-derivs,
# BSD-4-Clause, the JSON licence - is out: each puts a condition on the work
# that includes it which Apache-2.0 cannot carry. A repository that is itself
# GPL, or that only ships a dependency as a separate process, overrides this
# list with `licenses_allowlist`, or excuses one package in osv-scanner.toml.
